# Architecture

Crypto Workbench is organized as a staged pipeline.

## Components

- Orchestrator modules coordinate workflow stages.
- Corpus modules scan, classify, and rank source material.
- Paper modules locate metadata and compare versions.
- Parsing modules extract text, sections, notation, and pseudocode.
- Spec modules build review, notation, ambiguity, implementation, and test artifacts.
- Library modules map requirements to registries and tool support.
- Review modules run plan, cryptanalysis, side-channel, and security checks.
- Scaffolding modules initialize target workspaces and agent files.
